## 当前规范

以本目录当前程序的最终渲染、动效定义和参数为准。不得从旧版本记录、较早的样式声明或截图目测推导替代值。

- `visual-system.css`：唯一的项目样式入口，包含布局、白天/黑夜主题、组件、交互状态和响应式规则。
- `script.js`：当前动效定义、参数、预览、编辑、复制与存储行为。
- `assets/`、`vendor/`：界面资源与第三方库。
- `docs/CURRENT_SPEC.md`：当前约束与本次验证范围。

读取视觉数值时，在目标主题、窗口尺寸和交互状态下读取浏览器最终计算样式；同时检查卡片和弹窗实时预览。字体和部分图标使用外部 CDN，需联网加载。个人排序、默认参数等仍由浏览器保存。
