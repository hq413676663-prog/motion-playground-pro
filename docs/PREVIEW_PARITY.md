# 卡片与弹窗预览检查

检查版本：动效工坊 4.1，2026-10-09。

这是此前预览一致性检查的记录。之后的按钮配色、卡片视觉调整及文件整理见 `CHANGELOG.md`；本次发布检查见 `RELEASE_CHECK.md`。本页截图保留为历史检查资料。

## 修改内容

弹窗预览使用与卡片相同的 `demo-preview` 分类容器及 `anim-target` 结构，继续共用动效定义、参数同步和交互绑定。卡片组件专属的样式同时覆盖弹窗预览，避免通用按钮样式覆盖圆形按钮、图标和菜单组件。

浅色规则仍由 `body.light-theme` 限定，深色规则仍由 `body:not(.light-theme)` 限定。弹窗仅保留独立的舞台布局，不另设组件视觉规格。

## 检查范围

使用 Microsoft Edge 检查 111 项动效，包括选项卡 10、文字 18、按钮 18、卡片 29、列表 7、加载 28，以及内部数字动效 1。

每项分别核对浅色、深色主题的初始状态、交互后状态和再次交互后的状态。检查真实卡片打开的弹窗，覆盖桌面及 390px 窄屏。

核对组件结构、字体、字号、字重、文字颜色、背景、描边、圆角、阴影、间距、宽高、透明度、模糊、变换、动画时长和缓动，以及 `::before`、`::after`。循环动画统一播放时间点后比较，避免播放进度差异造成误报。

结果：未发现上述样式差异，未出现脚本错误。形变操作展开胶囊的浅色和深色截图已人工查看，图标和展开按钮正常显示。

截图：`preview-parity-light.png`、`preview-parity-dark.png`。
